📚 Student Management System
📌 Project Description
This project is a GUI-based Student Management System developed using Python. It allows users to add and view student details with permanent storage using JSON.
🚀 Features
Add student details
View student records
GUI interface using Tkinter
Data stored permanently using JSON file
Simple and user-friendly interface
🛠️ Technologies Used
Python
Tkinter (GUI)
JSON (Data Storage)
▶️ How To Run This Project
Install Python
Install VS Code (optional)
Download project files
Run the following command:
Copy code

python student_management.py
